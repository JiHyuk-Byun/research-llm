# V-DPM: Video Reconstruction with Dynamic Point Maps

## Main Claims

- V-DPM extends Dynamic Point Maps from image pairs to videos.
- The method adapts VGGT into a video Dynamic Point Map predictor using a small amount of synthetic data.
- The source claims state-of-the-art 3D and 4D reconstruction in dynamic settings.

## Evidence and Locations

- Abstract: explains that DUSt3R invariant point maps encode 3D shape and camera parameters but assume static scenes.
- Abstract: says Dynamic Point Maps represent dynamic 3D content and 3D scene motion, but prior DPMs were limited to image pairs and required post-processing for more than two views.
- Abstract: states that V-DPM reconstructs not only dynamic depth but the full 3D motion of every point in the scene.

## Methods / Approach

- Sets up Dynamic Point Maps for videos to improve representational power, neural prediction, and reuse of pretrained models.
- Implements the approach on top of VGGT.
- Uses synthetic data to adapt a static-scene VGGT model into a V-DPM predictor.
