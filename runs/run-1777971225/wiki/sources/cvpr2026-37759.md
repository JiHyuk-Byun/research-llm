# Ov3R: Open-Vocabulary Semantic 3D Reconstruction from RGB Videos

## Main Claims

- Ov3R performs open-vocabulary semantic 3D reconstruction from RGB video streams.
- The system predicts dense point maps from overlapping clips while adding object-level semantics.
- The source claims state-of-the-art performance in dense 3D reconstruction and open-vocabulary 3D segmentation.

## Evidence and Locations

- Abstract: identifies RGB video streams and Spatial AI as the setting.
- Abstract: describes CLIP3R as predicting dense point maps from overlapping clips with object-level semantics.
- Abstract: describes 2D-3D OVS as lifting 2D features into 3D through fused spatial, geometric, and semantic descriptors.

## Methods / Approach

- Uses CLIP-informed 3D reconstruction for geometry and object-level semantic prediction.
- Uses a 2D-3D open-vocabulary semantic module to lift 2D features into 3D.
- Integrates CLIP semantics directly into reconstruction.
