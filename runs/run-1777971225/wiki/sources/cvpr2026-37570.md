# ClipGStream: Clip-Stream Gaussian Splatting for Any Length and Any Motion Multi-View Dynamic Scene Reconstruction

## Main Claims

- ClipGStream targets long multi-view dynamic 3D reconstruction with large-scale motion.
- The method combines frame-stream scalability with clip-level consistency by optimizing at the clip level.
- The source claims state-of-the-art reconstruction quality and efficiency.

## Evidence and Locations

- Abstract: contrasts Frame-Stream methods, which scale but have poor temporal stability, with Clip methods, which have local consistency but high memory and limited sequence length.
- Abstract: describes short clips, clip-independent spatio-temporal fields, residual anchor compensation, inherited anchors, and inherited decoders.
- Abstract: claims scalable, flicker-free reconstruction with high temporal coherence and reduced memory overhead.

## Methods / Approach

- Divides sequences into short clips.
- Uses clip-independent spatio-temporal fields and residual anchor compensation for local variation.
- Maintains inter-clip structural consistency through inherited anchors and decoders.
