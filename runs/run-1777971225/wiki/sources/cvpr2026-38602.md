# DynamicVGGT: Learning Dynamic Point Maps for 4D Scene Reconstruction in Autonomous Driving

## Main Claims

- DynamicVGGT extends VGGT from static 3D perception to dynamic 4D reconstruction.
- The method learns dynamic point maps by jointly predicting current and future point maps in a shared reference coordinate system.
- The source claims improved reconstruction accuracy and temporal consistency in autonomous driving scenarios.

## Evidence and Locations

- Abstract: frames autonomous driving reconstruction as challenging due to moving objects, temporal variation, and complex scene dynamics.
- Abstract: describes a Motion-aware Temporal Attention module for motion continuity.
- Abstract: describes a Dynamic 3D Gaussian Splatting Head that predicts Gaussian velocities under scene-flow supervision.

## Methods / Approach

- Jointly predicts current and future point maps in a shared reference coordinate system.
- Uses temporal correspondence to learn dynamic point representations.
- Adds Motion-aware Temporal Attention for temporal dependencies.
- Adds a Dynamic 3D Gaussian Splatting Head with learnable motion tokens and scene-flow supervision.
