# LASER: Layer-wise Scale Alignment for Training-Free Streaming 4D Reconstruction

## Main Claims

- LASER converts an offline feed-forward reconstruction model into a streaming reconstruction system without retraining.
- The method targets streaming videos where offline models such as VGGT and pi^3 are limited by quadratic memory complexity.
- The source claims state-of-the-art performance on camera pose estimation and point map reconstruction while running at 14 FPS with 6 GB peak memory on an RTX A6000 GPU.

## Evidence and Locations

- Abstract: motivates the problem by stating that feed-forward reconstruction models have strong quality but cannot process streaming videos because of quadratic memory complexity.
- Abstract: attributes failures of simple Sim(3) temporal alignment to layer depth misalignment caused by monocular scale ambiguity across windows.
- Abstract: reports 14 FPS and 6 GB peak memory on an RTX A6000 GPU, plus state-of-the-art camera pose and point map reconstruction results.

## Methods / Approach

- Aligns predictions across consecutive temporal windows rather than retraining the base reconstruction model.
- Segments depth predictions into discrete layers.
- Computes per-layer scale factors and propagates them across adjacent windows and timestamps.
