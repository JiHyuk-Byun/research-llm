# MoRe: Motion-aware Feed-forward 4D Reconstruction Transrformer

## Main Claims

- MoRe is a feed-forward 4D reconstruction network for dynamic 3D scenes from monocular videos.
- The method addresses moving objects that corrupt camera pose estimation.
- The source claims high-quality dynamic reconstructions with exceptional efficiency.

## Evidence and Locations

- Abstract: states that dynamic 4D reconstruction is challenging because moving objects corrupt camera pose estimation.
- Abstract: describes an attention-forcing strategy that disentangles dynamic motion from static structure.
- Abstract: says grouped causal attention captures temporal dependencies and supports varying token lengths across frames.

## Methods / Approach

- Builds on a strong static reconstruction backbone.
- Uses attention forcing to separate dynamic motion from static structure.
- Fine-tunes on large-scale diverse dynamic and static scene datasets.
- Uses grouped causal attention for temporal coherence and variable token lengths.
