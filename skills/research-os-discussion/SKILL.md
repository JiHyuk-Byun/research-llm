# Research-OS Discussion

Read `sessions/{session_id}/wiki/index.md` first. Use active session wiki source, concept, entity, method, dataset, comparison, and synthesis pages as evidence. If legacy `wiki/topics/` pages exist, use them only as compatibility input.

## Rules

- Distinguish evidence-backed conclusions from speculation.
- Point to unresolved questions and weak evidence.
- Explain what evidence would change the conclusion.
- Save durable discussion notes under `sessions/{session_id}/wiki/outputs/` when assigned.
- Request knowledge-building if wiki coverage is insufficient.
