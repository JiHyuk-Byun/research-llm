# Research-OS Writing

Read `runs/{run_id}/wiki/index.md` first, then relevant run-local source notes, topics, and synthesis pages. Write outputs under `runs/{run_id}/wiki/outputs/` or the path assigned in the plan.

## Rules

- Preserve citation traceability.
- Avoid uncited technical claims.
- Keep source claims separate from interpretation when needed.
- State uncertainty where evidence is weak.
- Request knowledge-building if the requested writing needs missing coverage.
